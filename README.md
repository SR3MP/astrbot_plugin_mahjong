# astrbot_plugin_mahjong

![logo](logo.png)

立直麻将工具插件（AstrBot），适用于雀魂/天凤规则。

当前版本：**1.2.0**

## 功能

- 牌理分析：输入手牌，自动计算向听数、进张、最优切牌，支持赤牌
- 和牌计算：输入和牌牌面，自动计算役种、番数、符数、点数，亲家/子家结果同时输出

## 指令

### 牌理

```
牌理 <牌面>
```

```
牌理 123m234p345s11z
牌理 1234567m234p111z
```

### 和牌

```
和牌 <牌面>[+和牌] [选项]
```

```
和牌 123m234p456s11z+1z 自
和牌 123m(444p)345s11z+1z 荣和
```

门清不写条件默认按荣和非立直计算，结果后附加提示。

### 帮助

| 命令 | 说明 |
|------|------|
| 麻将帮助 / 立直帮助 | 完整帮助 |
| 牌理帮助 | 仅牌理用法 |
| 和牌帮助 | 仅和牌用法 |

### 选项

全称和缩写均可使用，缩写可连写（如 `立一自`），也可用空格隔开。

| 选项 | 缩写 | 说明 |
|------|------|------|
| 自摸 | 自 | 自摸和牌 |
| 荣和 | 荣 | 荣和（默认） |
| 立直 | 立 | 立直 |
| 一发 | 一 | 一发 |
| 场风 | — | 场风东/南/西/北，默认东 |
| 自风 | — | 自风东/南/西/北，默认东 |
| 宝牌 | d / dora | 宝牌个数，如 d1、dora3（不区分大小写） |
| 海底 | — | 海底摸月 |
| 河底 | — | 河底捞鱼 |
| 岭上 | — | 岭上开花 |
| 枪杠 | — | 枪杠 |
| 天和 | — | 天和（庄家起手和牌） |
| 地和 | — | 地和（闲家第一巡自摸） |

### 副露（仅和牌命令）

| 写法 | 含义 |
|------|------|
| `(111z)` 或 `（111z）` | 明刻/明顺/明杠 |
| `[1111m]` 或 `【1111m】` | 暗杠（需4张） |
| `[1m]` 或 `【1m】` | 暗杠简写（1张即代表4张） |

## 牌面格式

- 万子：`1m` ~ `9m`
- 饼子：`1p` ~ `9p`
- 索子：`1s` ~ `9s`
- 字牌：`1z`(东) `2z`(南) `3z`(西) `4z`(北) `5z`(白) `6z`(发) `7z`(中)
- 赤牌：`0m` / `0p` / `0s`
